# 我目前的技术栈：从 Java 后端到全栈协作

技术栈不是简历上的关键词集合，而是解决问题时真正能够调用的工具。下面这些内容，是我目前学习和实践中最常用的一部分。

![技术栈学习记录配图 w-100](/assets/desktop-banner/3.jpg "持续学习，持续实践")

## 后端：Java 是主线

Java 是我目前最主要的开发语言。使用 Spring Boot 可以较快地搭建服务和接口，MyBatis / MyBatis-Plus 则让我能够更直接地控制数据库访问和 SQL。

除了 Java，我也在使用 Go 和 Gin 了解更轻量的服务开发方式。不同语言的开发体验不一样，但接口设计、错误处理、数据校验和可维护性这些基本问题是相通的。

## 前端：能够完成完整闭环

我会使用 React 和 Vue，也会处理常规的 HTML、CSS 和 JavaScript 开发。我的目标不是把自己定位成只会某一个框架的开发者，而是能够理解前后端之间的数据流，独立完成接口对接，并在需要时快速定位问题属于哪一层。

这也是我维护个人博客的原因之一：它同时包含内容管理、页面展示、接口和部署，能够把很多零散的知识串起来。

## 数据库：先理解数据，再写 SQL

MySQL 和 PostgreSQL 是我目前主要接触的关系型数据库。除了 CRUD，我也在持续练习表结构设计、索引设计、查询分析和性能优化。

我越来越觉得，数据库能力并不只是记住 SQL 语法。理解数据之间的关系，知道一条查询为什么慢，以及明确什么数据应该由数据库处理、什么数据应该由服务层处理，同样重要。

## 工具与环境

Linux、Docker、Nginx、Tomcat、Git 和 Maven 是我日常学习与项目实践中经常使用的工具。它们让开发不止停留在本地代码，而是可以进一步走到构建、部署和运行维护。

接下来我会继续补足测试、微服务和系统设计方面的知识，同时把学到的内容尽量沉淀成可复用的项目和文章。
