# 把重复生图任务整理成 CSV：一个批处理工作流

需要为一组素材生成相似风格的图片时，逐条复制提示词很容易漏项，也不方便核对输出。LINUX DO 上 AIHelper 的批量生图更新帖展示了一种表格驱动流程：把每张图的提示词和目标文件名先整理好，再交给工具逐条处理。

![AIHelper 批量生图设置界面，截图来自原帖](/images/posts/linux-do/aihelper-batch-window.png)

## 先准备任务表

原帖中的 CSV 使用三列：

```csv
提示词,文件名,平台
为科幻主题设计一张横幅,scifi-banner,千问
为春日主题设计一张插画,spring-illustration,
```

平台列留空时会使用工具设置的默认平台。开始批量执行前，先统一文件命名规则、输出目录和图片比例等参数，后续就能通过文件名快速对应提示词。

![批量任务执行窗口显示提示词、文件名和生成状态](/images/posts/linux-do/aihelper-batch-settings.png)

## 先试运行，再批量执行

帖子展示的步骤是：选择 CSV 和保存目录，录制一次模型与生图选项的操作流程，先试运行确认页面可以正确回放，再启动批量任务。适合把它理解为“表格管理任务，界面自动重复操作”，而不是保证所有网站都能稳定兼容的通用 API。

正式跑之前，建议用两三条无关紧要的提示词做小批次验证：看模型和比例是否选对、文件是否落在预期目录、失败任务能否识别和重试。运行过程中避免同时手动操作同一个网页；平台界面更新后，录制步骤也可能需要重新检查。

通过浏览器界面自动化第三方服务前，确认该服务允许这种使用方式，并遵守它的速率与内容规则。能用官方批处理或 API 时，优先使用受支持的入口。
