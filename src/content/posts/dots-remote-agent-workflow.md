# 云端 Agent 和本地 Codex 怎么分工：先看任务在哪运行

我会按代码、凭证和计算资源实际所在的位置选择云端或本地 Agent。云端任务适合可异步、边界清晰的工作；本地 Agent 适合需要访问当前工作树的任务。两种方式都要明确验收条件、超时和取消路径。

云端和本地 Agent 的关键区别在于执行环境：

- **本地 Agent** 直接访问当前工作树和本机工具，适合需要即时交互的修改；
- **云端 Agent** 适合隔离、可异步的任务，但必须确认它拿到哪些仓库内容、凭证和网络权限；
- **远程派活** 要有清晰的验收标准、超时和取消方式，否则等待状态会取代真正的任务管理。

试用时先从只读、低风险任务开始，例如生成变更摘要或补一组单元测试。确认结果可信后，再逐步扩大权限。私有仓库、环境密钥和生产数据不要上传到不熟悉的云服务；结束任务后检查分支、产物和授权是否需要撤销。
