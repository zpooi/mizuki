# 你好，我是施光甲

你好，我是施光甲，也可以叫我 **zpooi**。

我目前就读于重庆城市科技学院软件工程专业，平时主要关注后端开发、全栈协作和工程实践。相比单纯把功能做出来，我更在意一个系统能不能稳定运行、能不能被维护，以及它是否真正解决了用户的问题。

## 我在做什么

我的主要技术方向是 Java 后端开发，常用 Spring Boot、MyBatis / MyBatis-Plus 构建接口和业务服务，也会使用 Go 和 Gin 进行服务开发。数据库方面主要使用 MySQL 和 PostgreSQL，平时也会关注表结构设计、索引和 SQL 性能。

前端并不是我的唯一方向，但我希望能够完成从接口设计到页面联调的完整链路。目前我会使用 React、Vue，以及 HTML、CSS 和 JavaScript，能够和前端一起把一个功能从想法推进到上线。

## 我经历过的项目

在中国信息通信研究院西部分院实习期间，我参与了政务数字化展示大屏项目，负责后端接口、数据清洗与聚合、数据库设计和部署运维等工作。这个项目让我更直观地认识到，真实业务里的开发不只是写代码，还包括数据质量、接口约束、系统稳定性和团队协作。

我也在维护自己的开源项目和这个博客。写博客对我来说不是简单地展示结果，而是把问题、方案和复盘留下来，方便未来的自己重新理解，也希望能给遇到相似问题的人一点参考。

## 这个博客会记录什么

- 后端开发与数据库实践
- 全栈项目中的接口设计和协作经验
- Linux、Docker 和部署运维中的问题
- 学习过程中的总结、踩坑和阶段性思考

如果你也对这些内容感兴趣，欢迎通过 [GitHub](https://github.com/zpooi) 找到我。
