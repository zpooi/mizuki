## 实习与项目实践

2025 年 1 月至 6 月，我在中国信息通信研究院西部分院担任后端开发实习生，参与政务数字化展示大屏项目。工作涉及 Spring Boot 数据接口、多源数据清洗和聚合、MySQL 表结构与查询优化、Python 数据处理脚本，以及接口联调和 Linux / Docker 环境部署。

这段经历让我看到，真实项目的工作并不止于接口返回成功：数据是否准确、响应是否稳定、错误能否定位、部署后是否方便维护，同样影响系统能不能可靠地解决问题。

## GitHub 项目

我会把学习和实践中的想法做成可以运行、迭代的小项目。公开仓库里有几类不同方向的尝试：

- **[ParkGuard](https://github.com/zpooi/ParkGuard)**：车辆挪车联系平台，包含微信小程序、Go API 服务和管理页面。项目让我练习了小程序流程、后端接口、PostgreSQL / Redis 和多进程部署之间的协作。
- **[ProxyForge](https://github.com/zpooi/ProxyForge)**：使用 Go 开发的代理网关，尝试把管理页面、代理转发和出口健康选择整合到一个服务中，也让我持续接触网络连接、隧道和服务运维问题。
- **[Mizuki](https://github.com/zpooi/mizuki)**：这个博客使用 Astro、TypeScript 和 Svelte 构建。我正在把它改成自己的技术记录站，也用它实践静态内容管理、页面组件和部署流程。
- **[ql_scripts](https://github.com/zpooi/ql_scripts)**：青龙定时任务脚本，包含开奖数据获取、历史预测核对和通知流程，是我练习 Python 自动化与数据处理的一个小项目。预测结果仅供技术实验和娱乐参考，不构成任何投注建议。
